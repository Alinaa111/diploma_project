# Development of a Computer Vision-Based Application for Assessing and Mapping the Physical Accessibility of Public Facilities for Wheelchair Users

## 1. Project Description

This diploma project aims to develop a computer vision-based application that helps wheelchair users assess the physical accessibility of public facilities in Astana, Kazakhstan. The application will use computer vision to automatically detect accessibility features and barriers from uploaded photographs, including ramps, stairs, entrances, curbs, and obstacles. Users will be able to view detection results, access detailed accessibility information, and explore public facilities through an interactive map.


## 2. Problem Statement

Wheelchair users often lack accurate and up-to-date information about the accessibility of public facilities. Existing mapping platforms may provide general accessibility ratings but do not always identify specific physical barriers. This project proposes using computer vision to automatically identify visible accessibility features and provide more detailed information about public facilities.

### Target Users

- Wheelchair users
- People with limited mobility
- Family members and caregivers
- Public facility managers and urban planners

### Expected Outcomes

- A manually annotated dataset of public facility images.
- A computer vision model capable of detecting selected accessibility features.
- Model evaluation using precision, recall, and F1-score.
- A prototype application for uploading and analyzing photographs.
- An interactive map displaying public facilities and accessibility information.

## 4. Project Scope and Current Status

### Project Scope

The project focuses on selected public facilities in Astana.

The computer vision component will detect:
- Wheelchair ramps
- Stairs
- Doors
- Obstacles
- Handrails

Additional field measurements cover entrances, ramps, doors, indoor routes, and toilets.

### Current Development Status
